# M11 — Domain Reference: Construction Workflows
**Version:** v1.0.0 | مرجع لتصميم وفحص التدفقات الأساسية. **هذه ممارسات عامة شائعة وليست مصدرًا معتمدًا**: كل خطوة أو نسبة أو شرط قانوني/تعاقدي (FIDIC، قانون المقاولات، ضرائب، تأمينات) يُعامل `UNVERIFIED` حتى يُتحقق منه بمصدر وتاريخ (سياسة الحداثة) ويراجعه مختص. المنتج يجعل ما يتغير بين الشركات **إعدادًا** (Mishel Brain) لا كودًا.

## كيف تُستخدم
لكل Flow: المدخلات → الخطوات → الكيانات → الاعتمادات → الأحداث → المخرجات → نقاط الخطر. يُقارَن بها الكود الحالي (COVERED/GAP) وتُشتق منها اختبارات Golden Flows.

## 1) Tender-to-Package (العطاءات)
- **خطوات:** Lead/فرصة ← قرار Bid/No-Bid ← استلام وثائق المناقصة ← مراجعة الشروط والمخاطر ← استخراج الكميات (BOQ/Takeoff) ← طلب أسعار الموردين/المقاولين الباطن ← تحليل أسعار وتكلفة مباشرة ← مصاريف عامة وأرباح ومخاطر ← تسعير ← مراجعة واعتماد ← عرض مالي وفني ← متابعة وتفاوض ← ترسية أو خسارة.
- **كيانات:** Opportunity، TenderDocument (مراجعات)، BOQItem، Takeoff، RateAnalysis، SupplierQuote، BidPackage، Approval، Outcome.
- **خطر:** كميات خاطئة، بند ناقص، أسعار قديمة، تسليم متأخر، شروط جزائية غير مرصودة.
- **تحويل عند الترسية:** Tender → Project مع BOQ مجمّد كأساس ميزانية (Baseline).

## 2) Procure-to-Pay (المشتريات)
- **خطوات:** طلب شراء (PR) من بند ميزانية ← مراجعة/اعتماد ← RFQ لعدة موردين ← مقارنة عروض (CBA) ← ترسية ← أمر شراء (PO) باعتماد حسب DOA ← استلام (GRN) وفحص جودة ← فاتورة مورد ← مطابقة ثلاثية (PO/GRN/Invoice) ← اعتماد ← دفع ← قيد وتحميل تكلفة المشروع.
- **كيانات:** PR، RFQ، Quote، Comparison، PO، GRN، Inspection، SupplierInvoice، Payment، Vendor، Budget Commitment.
- **خطر:** تجاوز الميزانية، فاتورة مكررة، استلام ناقص، فصل مهام (SoD)، تغيير سعر بعد الاعتماد.

## 3) Subcontract-to-IPC (مقاولو الباطن والمستخلصات)
- **خطوات:** تأهيل مقاول ← حزمة عقد (نطاق/BOQ باطن) ← تسعير ومفاوضة ← ترسية ← عقد وضمانات ← أمر تنفيذ ← تقدم فعلي (كميات منفذة معتمدة من الموقع) ← مستخلص (IPC) ← استقطاعات (محتجز، دفعة مقدمة، غرامات، مواد) ← مراجعة واعتماد ← دفع ← تتبع المحتجز والإفراج.
- **كيانات:** Subcontract، SubPackage، VO (أوامر تغيير)، ProgressMeasurement، IPC، Deduction، Retention، Guarantee، PaymentCertificate.
- **خطر:** صرف زائد عن المنفذ، كميات غير معتمدة، ضمانات منتهية، أوامر تغيير بلا تكلفة، ضرائب واستقطاعات حسب التشريع (يُتحقق).
- **جانب العميل (Owner IPC):** نفس الفكرة بعكس الاتجاه: مستخلص الشركة على المالك.

## 4) Plan-to-Control (التخطيط والتحكم)
- **خطوات:** WBS ← أنشطة وعلاقات ومدد ← موارد وتكاليف ← جدول أساس (Baseline) ← تحديث دوري (تقدم فعلي) ← تحليل المسار الحرج والانحراف ← Look-ahead ← تدفق نقدي ← Earned Value ← تقارير وإجراءات تصحيحية.
- **ربط:** BOQ ↔ WBS ↔ جدول ↔ تكلفة ↔ فواتير ↔ تقدم. تكامل Primavera/MS Project استيرادًا وتصديرًا.
- **كيانات:** WBS، Activity، Relationship، Calendar، Resource، Baseline، ProgressUpdate، Forecast.
- **خطر:** جدول غير مرتبط بالتكلفة، تحديث متأخر، Baseline يتغير بلا رقابة.

## 5) Claim-to-Evidence (المطالبات والتغييرات)
- **خطوات:** حدث (تأخير/تغيير/ظروف) ← إخطار في الميعاد التعاقدي ← تجميع الأدلة (مراسلات، تقارير يومية، صور، جداول) ← تحليل الأثر زمنيًا وماليًا ← إعداد المطالبة ← مراجعة ← تقديم ← تفاوض ← اتفاق/نزاع.
- **كيانات:** Event، Notice، Evidence، DelayAnalysis، Claim، VO، Response، Settlement.
- **خطر:** ضياع مهلة الإخطار، أدلة غير مؤرخة، تحليل غير مبرر. (المهل والأحكام تعاقدية/قانونية: تُتحقق.)

## 6) Site-to-Dashboard (الموقع)
- **خطوات:** تقرير يومي (عمالة، معدات، أنشطة، مشكلات، طقس) ← طلبات فحص مواد/أعمال (RFI/IR) ← عدم مطابقة (NCR) ← مخزن الموقع (استلام/صرف) ← قياس تقدم ← صور مؤرخة/موقعة ← ملخص لوحة تحكم للإدارة.
- **كيانات:** DailyReport، RFI، Inspection Request، NCR، SiteStock، Photo، Progress.
- **خطر:** إدخال متأخر، عمل دون اتصال (Offline) وتزامن، صور بلا سياق.

## 7) المستندات والمراسلات (Document Control)
- **خطوات:** تسجيل وثيقة بمراجعة (Revision) ← توزيع (Transmittal) ← مراجعة واعتماد (Submittal workflow) ← حالة (A/B/C/D…) ← أرشفة وربط بالمشروع/البند.
- **خطر:** العمل بمراجعة قديمة، ضياع سجل التوزيع.

## 8) الجودة والسلامة (QA/QC & HSE)
- **جودة:** خطة جودة، طلبات فحص، اختبارات مواد، NCR/CAR، إغلاق بدليل.
- **سلامة:** تصاريح عمل، تقييم مخاطر، حوادث وشبه حوادث، تفتيش، تدريب، مؤشرات (يُتحقق من متطلبات الجهة المحلية).

## 9) الموارد والمعدات والأصول
- معدات: تخصيص للمشروع، ساعات تشغيل، صيانة، تكلفة تحميل.
- عمالة: حضور، إنتاجية، تكلفة، عقود/تأمينات (يُتحقق من التشريع).
- مخزون: أصناف، مخازن، حركات، جرد، متوسط تكلفة.

## 10) المالية للمقاولات
- شجرة حسابات ومراكز تكلفة بالمشروع/البند، تحميل التكلفة الفعلية، الالتزامات، الإيراد حسب نسبة الإنجاز (تُحدد السياسة المحاسبية مع مختص)، المحتجز، الضمانات، التدفق النقدي، العملات، الضرائب (يُتحقق من الإقرارات المحلية).

## 11) تحويلات بين التدفقات (الربط التلقائي)
| من | إلى |
|---|---|
| Tender مرسّى | Project + Baseline Budget + WBS مبدئي |
| BOQ | PR / Subcontract Package |
| PO / Subcontract | Commitment (التزام) |
| GRN / Progress معتمد | تكلفة فعلية + حق مستحق |
| Invoice / IPC معتمد | AP/AR + قيد |
| Progress فعلي | تحديث الجدول + EV |
| VO معتمد | تعديل العقد والميزانية بتتبع |
كل تحويل: حدث (Event) + Idempotency + أثر محاسبي + Audit.

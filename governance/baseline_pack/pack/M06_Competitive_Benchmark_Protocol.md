# M06 — Competitive Benchmark & Proof Protocol
**Version:** v1.0.0 | هدفه: معرفة أين نتعادل ونتفوق ونتأخر، بالأدلة. ممنوع أي ادعاء تفوق بدون قياس.

## 1) نطاق المقارنة
| الفئة | أمثلة (تُراجع وتُوسَّع) |
|---|---|
| ERP عام | Odoo، SAP S/4HANA، Microsoft Dynamics 365، Oracle |
| تحكم مشاريع وجداول | Oracle Primavera (P6/Unifier)، Microsoft Project |
| إدارة إنشاءات | Procore، Autodesk Construction Cloud/Docs |
| مقاولات متخصصة | حلول Estimating/BOQ وCost وContracts (يُبحث عنها) |
| منافسون إقليميون ومحليون | تُحدد بالبحث، لا بالذاكرة |
| بدائل Excel/مخصص | واقع أغلب الشركات، وهو أهم منافس فعلي |
> القائمة بداية. يملؤها الـ AI من بحث فعلي ويعرضها على Owner.

## 2) المصادر المقبولة
Tier 1: توثيق رسمي وصفحات المنتج وRelease notes · Tier 2: تقارير محايدة وتجارب مجانية · Tier 3: مراجعات مستخدمين (للاكتشاف) · Tier 4: مجتمعات. كل خلية: **المصدر + الرابط + تاريخ الاطلاع**. بدونها `UNVERIFIED`.

## 3) مصفوفة القدرات
الصفوف = Capability Families (86) ومجموعات M من خطة الاستكمال. الأعمدة: MISHEL (الحالة VERIFIED/COVERED/GAP) · كل منافس: (يدعم أصيلًا / عبر Add-on / عبر شريك / لا يدعم / UNVERIFIED) · ملاحظة العمق · المصدر.
**تعريف العمق:** 0 لا يوجد · 1 أساسي · 2 متوسط · 3 متقدم · 4 رائد. تعيين العمق بدليل (توثيق أو تجربة) فقط.

## 4) التصنيف النهائي لكل قدرة
`LEAD` (نتفوق بدليل) · `PARITY` · `BEHIND` · `DIFFERENTIATOR` (لا يقدمه الآخرون كما نقدمه) · `NOT-A-GOAL`. الحالة الابتدائية لكل خلية: `HYPOTHESIS` حتى تثبت.

## 5) الفرضيات (H1–H7) وإثباتها
راجع خطة الاستكمال §1. كل فرضية تحتاج: سيناريو قياس + بيانات + معيار نجاح من Owner + نتيجة + مصدر.

## 6) Golden Flows للقياس
1. Tender-to-Package · 2. Procure-to-Pay · 3. Subcontract-to-IPC · 4. Plan-to-Control · 5. Claim-to-Evidence · 6. Site-to-Dashboard.
لكل Flow: بيانات حقيقية سابقة (مُجهَّلة) · نتيجة مرجعية · مقاييس (زمن، خطوات، أخطاء، تدخل بشري، دقة الأرقام) · قياس MISHEL + قياس بديل (الأداة الحالية للعميل/تجربة منافس إن أمكن).

## 7) تجربة المنافسين عمليًا
حيث تتوفر تجارب مجانية/Demo: تنفيذ Flow واحد على الأقل بخطوات موثقة (لقطات، عدّ الخطوات، الزمن). **لا تُنسب نتيجة لمنتج لم يُجرَّب فعلًا.**

## 8) ما بعد المقارنة
- Differentiation Map: أين نستثمر (DIFFERENTIATOR) وأين نكتفي بـ PARITY وأين نشتري/نتكامل.
- يُغذي P4 (Scope/Tiers) وترتيب الأولويات.
- Competitive Proof (P15): إعادة المقارنة على النسخة العاملة.

## 9) سياسة الادعاءات
مواد التسويق والعروض لا تحتوي إلا ما ثبت في المصفوفة بـ VERIFIED/قياس. «أفضل من Odoo/SAP» ممنوعة؛ البديل: «أسرع بنسبة X في Flow Y (قياس بتاريخ كذا)». أي إشارة لعلامة منافس تراجع قانونيًا.

## 10) معايير القبول
- [ ] كل خلية بمصدر وتاريخ أو UNVERIFIED. [ ] مجموعة المنافسين معتمدة من Owner. [ ] Differentiation Map. [ ] خطة قياس للـ Golden Flows بمعايير Owner. [ ] لا ادعاء بلا قياس.

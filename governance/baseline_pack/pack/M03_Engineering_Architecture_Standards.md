# M03 — Engineering & Architecture Standards (المعايير الهندسية والمعمارية)
**Version:** v1.0.0 | تُطبَّق على كل Module Spec وكل Prompt Slice. بند لا يُطبَّق يُسجَّل `N/A` بسبب.

## 1) المعمارية العامة
- **Domain-Modular:** Bounded domains بحدود واضحة، لكل domain مالك وواجهة (API/Events) وبياناته. لا وصول مباشر لجداول domain آخر.
- **طبقات:** Control Plane (هوية، مستأجرون، إعداد، صلاحيات، ترخيص) · Transactional Core (ERP) · Engineering/Rules Plane · AI Plane · Integration Plane · Analytics/Search/RAG مشتقة (قراءة فقط من المصدر).
- **مصدر الحقيقة:** معاملات قوية محلية في Postgres؛ الفهارس/RAG/BI نسخ مشتقة قابلة لإعادة البناء.
- **API-first وEvent-capable.** كل قدرة تُعرَّض API ثابتة النسخة وتصدر أحداثًا.
- **Evolution-ready:** Modular Monolith أولًا، مع حدود تسمح بالفصل لاحقًا. لا Microservices قبل ضرورة مقاسة.

## 2) البيانات
- المفاتيح: UUID/ULID، مفاتيح أعمال فريدة حسب المستأجر.
- كل جدول أعمال: `tenant_id, company_id, [project_id], created_at/by, updated_at/by, version, status`.
- **Row-Level Security** أو عزل معادل مُختبر Runtime. السياق من الجلسة الموثقة.
- **الزمنية (Temporal):** قيم تتغير بالزمن (أسعار، أسعار صرف، أدوار) تُخزَّن بصلاحية من/إلى.
- **المال:** DECIMAL بدقة محددة، عملة لكل مبلغ + سعر الصرف وتاريخه. لا Float.
- **الحذف:** Soft-delete/Archival، والسجلات المعتمدة غير قابلة للتعديل.
- **الاحتفاظ والخصوصية:** تصنيف بيانات شخصية/حساسة/تجارية، وسياسة احتفاظ وحذف/تصدير لكل نوع.
- **الترحيل:** migrations متسلسلة، قابلة للإعادة من الصفر، بـ checksum، مع خطة Rollback.

## 3) المعاملات والتزامن
- كل عملية أعمال في معاملة واحدة مع قيود DB (Unique, FK, Check).
- **Idempotency Keys** لكل عملية خارجية/استدعاء متكرر.
- **Concurrency:** Optimistic locking بالنسخة، وSerializable/Advisory locks في المسارات المالية الحرجة.
- **Period-lock** مالي؛ لا ترحيل في فترة مقفلة.
- **Saga/Compensation** للعمليات متعددة الخطوات والتكاملات الخارجية.

## 4) الـ Workflow والصلاحيات
- Workflow Engine بحالات وانتقالات معرّفة (State Machine) وإصدارات للتعريفات.
- RBAC + ABAC + DOA (عتبات مالية قابلة للضبط، لا تُخترع) + SoD + Maker/Checker، ومنع الاعتماد الذاتي.
- الاعتماد المتعدد وSLA وتصعيد وتفويض مؤقت.
- كل قرار صلاحية يُسجل (من، ماذا، لماذا سُمح/رُفض).

## 5) الأحداث والتكامل بين الأقسام
- **Outbox pattern** لنشر الأحداث من المعاملة.
- **Event Catalog:** الاسم، المنتج، المستهلكون، المخطط (Schema)، النسخة، الأثر.
- المستهلكون Idempotent، وفيها Retry وDead-letter ومراقبة.
- لا إدخال مكرر: الحدث ينقل البيان للقسم التالي.

## 6) واجهات البرمجة
- REST/JSON مع OpenAPI، ويُضاف GraphQL أو غيره فقط بمبرر.
- ترقيم نسخ، Pagination، Filtering، Error model موحد، Rate limits، Webhooks موقعة.
- التوافق الخلفي لنسخة API مدة محددة، وسياسة Deprecation.
- توافق MCP للأدوات التي تُعرَّض للـ Agents (بصلاحيات محدودة).

## 7) الواجهة والتجربة
- حسب الدور (Role-based)، بساطة قابلة للقياس (خطوات، زمن أول قيمة).
- عربي RTL / إنجليزي LTR كاملان، وMobile/Offline للموقع مع مزامنة وحسم تعارضات.
- Accessibility، وحالات فارغة وأخطاء واضحة، وتصميم نظام (Design System) واحد.

## 8) الإعداد بدون Fork (Mishel Brain)
- كل ما يخص الشركة (هيكل، أدوار، إجراءات، DOA، Workflows، نماذج، قوالب، مكتبات حسابات، لوحات، مظاهر، تعليمات الـ Agents) **بيانات إعدادية بنسخ**، ليست كودًا.
- ترقية المنتج لا تمسح الإعداد. تعارض الإعداد مع الإصدار الجديد يُكشف ويُعرض.

## 9) التكاملات
لكل تكامل: الاتجاه، التعيين (Mapping)، التكرار والـ Idempotency، الأخطاء والتسوية (Reconciliation)، الاعتمادية (Circuit breaker)، الاختبار بعقود (Contract tests). الأولوية: Excel/CSV · Primavera/MSP · Revit/AutoCAD/IFC · SAP/Odoo/محاسبة · البريد/التقويم · SSO (SAML/OIDC) · n8n/Webhooks/MCP.

## 10) الأداء والتوسع
أهداف زمن استجابة وحجم بيانات لكل موديول تُحدد قبل البناء. فهارس وخطط استعلام مراجعة. مهام خلفية بطوابير. اختبار حمل وتحمل (Soak). التخزين المؤقت له سياسة إبطال.

## 11) المراقبة والتشغيل
Logging منظم مع Correlation IDs · Metrics · Tracing · تنبيهات · Health checks · نسخ احتياطي واستعادة مُختبرة · DR بأهداف RPO/RTO يحددها Owner · إدارة الإصدارات والترقية والتراجع · SBOM وفحص تبعيات.

## 12) الأمان (ملخص — التفاصيل M04)
Zero Trust · أقل صلاحية · تشفير أثناء النقل والتخزين · إدارة أسرار خارج الكود · تدقيق كامل · عزل المستأجرين · فحص ثغرات.

## 13) الجودة والبناء
TypeScript صارم · Lint/Format · Code review · اختبارات لكل متطلب (Test ID) · تغطية للمسارات الحرجة · لا Merge بدون CI أخضر · وثائق API تُولَّد · ADRs لكل قرار معماري كبير.

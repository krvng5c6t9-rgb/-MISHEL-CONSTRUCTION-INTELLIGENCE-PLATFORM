# M05 — AI, Agents & Automation Governance Standard
**Version:** v1.0.0 | المبدأ: AI يساعد ويقترح ويحرر؛ الحقائق المالية والكميات والتواريخ من قاعدة البيانات أو قواعد حتمية؛ والقرار الجوهري بشري.

## 1) طبقة AI
- **AI Gateway:** نقطة واحدة لكل استدعاءات النماذج: مصادقة، صلاحيات، تسجيل، حصص، فلترة، توجيه.
- **Registries:** Models · Prompts · Tools · Skills · Agents، كلها بنسخ ومالك وحالة.
- **Model Routing:** اختيار النموذج حسب المهمة والتكلفة والخصوصية، مع Fallback.
- **التكلفة:** رموز/زمن/تكلفة لكل مستأجر وAgent وميزة، وحصص وتنبيهات.
- **Kill Switch:** إيقاف فوري لكل Agent/ميزة/نموذج على مستوى المستأجر أو النظام.

## 2) المعرفة (RAG) وذاكرة المشروع
- مصادر معتمدة فقط، بصلاحيات المستخدم (لا يرى الـ AI ما لا يراه المستخدم).
- Citations إلى المصدر وموضعه. «الاستشهاد ≠ الانطباق»: تحقق من سريان الوثيقة وإصدارها.
- فهارس مشتقة قابلة لإعادة البناء، مع تحديث عند تغيير المصدر.
- معايير وأكواد: Edition + Year + Jurisdiction + Status.

## 3) الـ Agents
- **Agent Factory:** تعريف Agent = غرض · مدخلات · أدوات مسموحة · صلاحيات · مخرجات · حدود · Prompt Version · Evals.
- **أنواع:** هندسي، تجاري/تندر، تخطيط، مالي، مشتريات، مكتب فني، جودة، سلامة، وثائق، دعم.
- **Multi-Agent:** تفويض بين Agents بصلاحيات محدودة ومراقبة؛ لا يرث Agent صلاحيات أعلى من المستخدم الذي استدعاه.
- **Tool Calling:** «Prompt ≠ تفويض» و«توفر أداة ≠ صلاحية». كل أداة لها فحص صلاحية خادمي، وتأكيد بشري للإجراءات ذات الأثر.
- **نمط الاستقلالية:** `Shadow` (يقترح بدون أثر) ← `Assist` (يجهز ويطلب موافقة) ← `Act` (ينفذ ضمن حدود). الترقية لمرحلة أعلى بنتائج Evals وقرار Owner.

## 4) HITL ونقاط الاعتماد
إلزامي بشريًا: ما يحرك أموالًا، أو يصدر وثيقة تعاقدية/رسمية، أو يتعلق بالسلامة، أو يعتمد رسومات/كميات للتسعير، أو يغير بيانات رئيسية. يُسجل: من اعتمد، ماذا رأى، متى.

## 5) الحماية
- **Prompt Injection:** المحتوى الداخل (ملفات، بريد، ويب) بيانات لا أوامر؛ عزل التعليمات، فلترة، حدود أدوات، اختبارات هجوم.
- **تسريب بيانات:** إخفاء/تجهيل البيانات الحساسة قبل النماذج الخارجية حسب السياسة؛ عدم التدريب على بيانات العميل ما لم يُتفق؛ إقامة البيانات.
- **المخرجات:** التحقق من المخطط (Schema)، حدود الأرقام، منع اختلاق المصادر.
- **سجل كامل:** المدخل، السياق المسترجع، الأدوات، المخرج، القرار البشري.

## 6) التقييم (Evals)
- **Golden Datasets** لكل ميزة: حالات حقيقية سابقة (مُجهَّلة) بنتيجة مرجعية معروفة.
- مقاييس: دقة الحقول والأرقام، الاسترجاع، الاستشهاد الصحيح، المعدل المقبول للأخطاء، التكلفة، الزمن.
- **حدود القبول يحددها Owner** لكل ميزة؛ ولا تُسلَّم ميزة AI لعميل قبل اجتيازها.
- اختبارات Regression عند تغيير نموذج أو Prompt أو بيانات. Red-team دوري.
- مراقبة الانحراف في الإنتاج وتغذية راجعة من المستخدمين.

## 7) ميزات AI الأساسية وشروطها
| الميزة | شرط خاص |
|---|---|
| فهم الرسومات واستخراج الكميات | عينة تندرات سابقة بنتائجها؛ مراجعة بشرية إلزامية؛ إعلان نسبة الثقة؛ لا اعتماد تلقائي للكميات |
| مطابقة BOQ والتوصيف | مقارنة بمقايسات معتمدة؛ تسجيل أنواع الأخطاء |
| التسعير وتحليل الأسعار | مصدر السعر وتاريخه ظاهر؛ لا سعر مختلق؛ حدود تسامح |
| مراجعة العقود | إشارة للبند؛ لا رأي قانوني نهائي؛ مراجعة مختص |
| التقارير والمخرجات | الأرقام من قاعدة البيانات؛ توليد النص فقط |
| المساعدات (Chatbots) | تحترم الصلاحيات؛ تقول «لا أعرف» عند غياب الدليل |

## 8) الأتمتة وn8n والتكاملات
- n8n/محركات الأتمتة طبقة تنسيق تكامل، **ليست مصدر منطق الأعمال المعتمد**.
- كل Workflow خارجي: هوية خدمة بصلاحيات دنيا، Idempotency، Retry، Dead-letter، مراقبة، توقيع Webhooks.
- أي إجراء ذي أثر مالي/تعاقدي يمر عبر واجهة المنتج المعتمدة، وليس مباشرة على الجداول.

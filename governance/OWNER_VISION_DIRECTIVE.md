# Owner Vision Directive (OVD-001) — recorded 2026-10-15

Source: the owner's own words in the working session after Stage 36 (Arabic), recorded here so nothing is lost
between sessions. The owner stated these are **examples only**: the master plan must cover every department, role,
cycle and link of a large construction company, not only what is listed here. Status: input to the Master Plan
(MP-01…), not yet decomposed or prioritised. Nothing here is a claim that it exists in the code.

## 1. Product ambition
- One integrated, sellable, AI-native construction enterprise system covering the roles that today use Odoo, SAP
  (ERP), Primavera, Power BI, Excel, PowerPoint, AutoCAD, Revit (architecture, structure, MEP, civil), SAP2000,
  3ds Max — taken over or integrated so the engineer works inside one system.
- Everything dynamic: one change updates everything that depends on it (database rules + events; AI where judgement
  is needed). One-click actions per screen ("review", "price", "prepare").
- AI agents act in each role (technical office engineer, estimator, planner, contracts engineer, designer, QS,
  accountant…); an assistant inside every screen with the user's own permissions.
- Use all suitable open-source libraries/tools that do the same work (licences checked before use).
- Everything exportable and printable in defined forms / documents / BOQs (PDF, Excel, Word, PowerPoint).
- One UI/UX design system (theme, main and sub sections, screens), Arabic and English.
- Multi-project company: departments, projects from tender to close-out.

## 2. Examples given by the owner (non-exhaustive)
- **Tender study:** upload tender documents → review BOQ, specifications and pricing; breakdown per item; dry cost,
  indirect cost, budget, profit, best execution duration; notes; go / no-go; based on Egyptian-market experience
  (company data, supplier prices, history — never invented).
- **Contract review** like a contracts engineer; **design package review** like a technical-office engineer.
- **After award — project file:** realistic cost/cash-loaded time schedule (Primavera-like engine in the system:
  WBS, activities, relationships, calendars, resources, baseline, CPM, look-ahead; XER/XML exchange); technical
  office target plan; commercial target plan; submittal / approval list; drawings list; materials and procurement
  list; **pre-construction BOQ** (actual budget, described by execution steps, materials, types and codes);
  shop drawings for all disciplines; then execution follow-up.
- **Technical office with AI:** coordination, clash detection, shop drawings, sections and details, quantity
  take-off — AI acting as the engineer and driving Revit / AutoCAD (MCP / APIs) and/or an in-system IFC engine.
- **Interior design department:** take the as-built → correct it → 5 furniture layout proposals → approved one
  developed into a 3D interior design in a chosen style (classic, modern, semi-classic, ultra-modern, …) → 3D
  package with a BOQ described by materials and quantities → 2D design package → client approval → shop drawings
  → execution.
- **Owner portfolio dashboard:** all projects, phases, KPIs, planned / earned / actual, progress, problems; drill
  into any project; the same per department.
- **Organisation:** full organisation chart from founder / CEO to office boy, with tasks, responsibilities, outputs
  and authorities; master method statement; forms and documents per process.
- **Workforce gap alarm:** missing positions per department / project / discipline with expected salaries;
  company's monthly commitments (payroll, subcontractors, suppliers, instalments).
- **Data:** the owner enters company data once (people, salaries, rates, history); every later update is made
  inside the system.

## 3. Owner time target and the engineering position
- Owner target: launch announcement within one week; whole project within one to two months.
- Position recorded (E4 estimate, not evidence): the full scope above cannot be built and verified in that time.
  The plan must therefore define a first release that is real, tested and honestly described, and a sequence of
  releases for the rest. No feature is to be announced or shown as working before it exists and passes its gate.

## 4. Competitors named by the owner (to analyse in the master plan)
cmicglobal.ae (CMiC), hajjaj.pro, madarasystems.com, buildo.solutions, pioneers-solutions.com, bysmart-soft.com.
These sites cannot be opened from the build environment (DNS blocked). Web search returned facts only for CMiC (one
database across financials, project controls, field and HR; NEXUS AI with 25+ agents, 2026; P6 / MS Project
integration; aggregator and vendor sources). No reliable facts were found for the others — no claim about them until
the owner allows the domains or sends their pages.

## 5. Governance unchanged
AI is never the sole authority for financial, contractual, engineering or safety decisions; licensed drawings,
prices, DOA values and company policies come from the owner; no evidence → no claim.

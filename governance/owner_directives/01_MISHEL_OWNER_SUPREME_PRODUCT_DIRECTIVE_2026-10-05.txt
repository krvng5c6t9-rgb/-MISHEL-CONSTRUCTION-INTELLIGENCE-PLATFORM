============================================================ 1) قرار
المالك — افهم المهمة قبل أي شيء
============================================================

هذا المشروع ليس ERP تقليديًا، وليس Construction ERP فقط، وليس مجموعة
Modules بجوار بعضها، وليس Chatbot مضافًا إلى برنامج، وليس مجرد إصلاح
للنسخة الحالية، وليس الهدف إعادة إنتاج SAP أو Odoo أو Procore أو
Primavera.

الهدف هو بناء منتج تجاري Enterprise شديد الاتساع والاحتراف يمثل “شركة
مقاولات وهندسة رقمية متكاملة” ويعمل كـ:

AI-Native Autonomous Construction Enterprise Operating System +
Enterprise Company Operating System + Project & Portfolio Management
Operating System + Engineering & Technical Office Operating System +
Commercial / Contracts / Finance Operating System + Digital Workforce +
Expert & Consultant Intelligence System + Company Digital Twin +
Enterprise Knowledge Graph / Company Brain + Workflow / Rules / Event /
Automation Fabric + Agent / Skill / Tool Factory + Decision / Simulation
/ Predictive Intelligence + Commercial Multi-Tenant SaaS Platform.

المطلوب أن يغطي النظام الشركة والمشروعات والهندسة والإدارة والعمليات
والقرارات والمستندات والبيانات والأدوات من البداية إلى النهاية، وأن
يستطيع تنفيذ أو إعداد أو تعديل أو مراجعة أو تحليل أو تنسيق أو متابعة أو
توقع أو إخراج أكبر قدر ممكن من الأعمال التي يقوم بها الأشخاص والإدارات
داخل شركة مقاولات Enterprise، مع Human Governance واعتمادات وصلاحيات
واضحة عندما يكون القرار حساسًا أو يحتاج مسؤولية بشرية متخصصة.

لا تختزل هذا التعريف في قائمة Modules.

الأدوات والصلاحيات والحوكمة — على القيام بأعمال هذه الوظائف.

أمثلة توضيحية فقط وليست Scope مغلقًا:

-   مهندس التنفيذ: متابعة الأعمال، quantities/progress، site records،

    النتائج بباقي النظام.
-   مهندس/إدارة المكتب الفني: drawings، revisions، RFIs، submittals،
    BOQ، quantity takeoff، method statements، technical comparisons،
    coordination، change/impact identification، as-built/handover
    outputs.
-   Planning Engineer/Manager: إنشاء وتعديل وتحديث وتحليل البرنامج، WBS،
    logic، resources، baselines، lookaheads، progress، critical path،
    recovery، delay analysis، curves، forecasts، EVM والتقارير.
-   Estimator/Tender Engineer: قراءة Tender Package، completeness،
    drawings/specs/BOQ review، quantities، rate build-ups،
    supplier/subcontractor quotations، indirect costs، preliminaries،
    risks، bid strategy، tender outputs.
-   Commercial/Contracts: contracts، variations، claims، notices، EOT،
    entitlements، commercial exposure، subcontract administration،
    valuation، change control.
-   Finance: budgets، cash positions، payables/receivables، treasury،
    forecasting، controls، postings والتقارير حسب النظام المحاسبي
    المعتمد.
-   Procurement/Warehouse: planning، RFQ، technical/commercial
    comparisons، approvals، PO، expediting، receipt، inspection،
    inventory، issue/return/transfer/reorder، supplier performance.
-   Management: portfolio/company intelligence، scenarios، decisions،
    approvals، alerts، exceptions، forecasts.

لا تعتبر هذه الأمثلة كاملة. اكتشف باقي الوظائف بنفس العمق.

============================================================ 8) الشركة
“تسمع في بعضها” — Event-Driven Enterprise
============================================================

هذه نقطة جوهرية وغير قابلة للاختزال.

أي تغيير أو Event يجب أن يستطيع إطلاق Impact Propagation لكل ما يرتبط به
وفق Knowledge Graph + Business Rules + Event Bus + Workflow Engine +
Automation + Agents.

مثال: Drawing Revision → Engineering Review → Quantity/BOQ Impact →
Schedule Impact → Cost/Budget/Forecast Impact →
Procurement/PO/Subcontract Impact → Site Impact →
Commercial/Variation/Claim Impact → Cash Flow → Risk → Relevant
approvals/notifications → Dashboards/Management.

ومثال: Actual Site Progress / Quantity Change → Progress → Schedule →
Resources → Cost → Forecast → Cash Flow → IPC → Procurement → Inventory
→ Subcontractor → Commercial → Finance → Risk → Executive Intelligence.

لا hard-code هذين المثالين فقط. صمم General Event/Dependency/Impact
Architecture.
